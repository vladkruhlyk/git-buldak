# Buldak опт — лендінг

Односторінковий лендінг оптових поставок корейської локшини Buldak.
Уся конверсія веде в Telegram-канал: форми на сторінці немає.

## Запуск

```bash
npm install
npm run dev
```

## Де що правити

| Що | Файл |
|---|---|
| Тексти, смаки, ціни за обсягом, умови, FAQ, відгуки | `lib/content.ts` |
| Телефон, посилання на Telegram, Meta Pixel | `lib/config.ts` |
| Верстка секцій | `app/page.tsx` |
| Фото пачок і логотип | `public/` |

Фото пачок — PNG з вирізаним фоном, збережені у WebP. Вихідник знімка
Carbonara лежить у корені (`carbonara-source.png`) на випадок перезбірки.

## Важливо перед запуском реклами

- `lib/config.ts` містить телефон, Telegram і Meta Pixel, перенесені з
  проєкту Asia Foods. Якщо у Buldak свої — замініть.
- Ціни в `PRICE_TIERS` діють на Carbonara та Cheese; на решту смаків
  сторінка чесно каже «прайс за запитом».
